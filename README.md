# portopt

Portfolio allocation research toolkit: data, risk-based estimators, walk-forward backtesting, performance and risk metrics, charts.

![Growth of 1](docs/figures/report_01_wealth.png)

**Documentation**
- [`examples/getting_started.ipynb`](examples/getting_started.ipynb): getting-started notebook (executed, with outputs).
- [`docs/user_guide.pdf`](docs/user_guide.pdf): user guide (installation, modules, recipes, common errors, API reference).
- [`docs/methodology_en.pdf`](docs/methodology_en.pdf) (EN) and [`docs/methodology.pdf`](docs/methodology.pdf) (FR): definitions, results and proofs for every method.
- LaTeX sources in `docs/*.tex`; build with `cd docs && latexmk -xelatex <file>.tex`.

## Structure

```
portopt/
├── data.py         # yfinance -> cleaned prices -> returns; realistic multi-asset simulator
├── estimator.py    # 1/N, InverseVolatility, RiskParity (budgets), ERC, HRP; sample / Ledoit-Wolf / EWMA covariances
├── backtester.py   # Backtester(returns, estimator, in_sample, out_of_sample) -> OOS returns net of costs
├── metric.py       # CAGR, vol, Sharpe, Sortino, Calmar, drawdowns, VaR/CVaR, PSR, summary()
├── plot.py         # white-background charts, colour-blind-safe palette, full PNG report
└── fonts/          # Space Grotesk / Space Mono (OFL)
docs/
├── METHODOLOGY.md     # earlier markdown version (the PDF is the reference)
├── methodology.tex    # methodology, French (-> methodology.pdf)
├── methodology_en.tex # methodology, English (-> methodology_en.pdf)
├── user_guide.tex     # user guide (-> user_guide.pdf)
├── make_figures.py    # regenerates every figure in the guide
└── figures/
examples/run_backtest.py            # full command-line comparison
examples/getting_started.ipynb      # getting-started notebook (generated by build_getting_started.py)
tests/              # theoretical properties, no look-ahead, backtest maths, metrics
```

## Usage

```python
from portopt import load_returns, ERC, HRP, EqualWeight, Backtester, run_backtests, summary
from portopt import plot

R = load_returns(["SPY", "TLT", "GLD", "DBC", "EFA"], start="2008-01-01", cache_dir="data_cache")

# one strategy
bt = Backtester(R, ERC(cov_method="ledoit_wolf"), in_sample=252, out_of_sample=21,
                transaction_cost_bps=5)
oos = bt.run()              # pd.Series of OOS returns net of costs
bt.weights_                 # target weights at each rebalance
bt.turnover_                # one-way turnover at each rebalance
bt.risk_contributions()     # ex-ante risk contributions at each rebalance

# several strategies
rets, bts = run_backtests(R, {"1/N": EqualWeight(), "ERC": ERC(), "HRP": HRP()}, 252, 21,
                          transaction_cost_bps=5)
summary(rets, turnover={k: b.annualized_turnover() for k, b in bts.items()})

# chart report (13 PNGs)
plot.save_report(rets, bts, "outputs/charts")
```

Full example on 10 multi-asset ETFs:

```bash
python examples/run_backtest.py              # Yahoo Finance data since 2008
python examples/run_backtest.py --synthetic  # offline, simulated data
```

## Methods

| Estimator | Principle | Parameters |
|---|---|---|
| `EqualWeight` | $w_i = 1/N$ | |
| `InverseVolatility` | $w_i \propto \sigma_i^{-k}$ | `exponent` |
| `RiskParity` | $w_i(\Sigma w)_i / w^\top\Sigma w = b_i$, solved by coordinate descent on Spinu's convex formulation | `budgets`, `tol`, `max_iter` |
| `ERC` | `RiskParity` with $b_i = 1/N$ | |
| `HRP` | hierarchical clustering + recursive bisection (López de Prado, 2016) | `linkage`, `split="bisection" \| "dendrogram"` |

All estimators accept `cov_method="sample" | "ledoit_wolf" | "ewma"` or a callable `returns -> ndarray`.

To add a method, subclass `BaseEstimator` and implement `_compute_weights(returns) -> np.ndarray`.

## Charts

`portopt.plot`: white background, embedded Space Grotesk typography, categorical palette validated for colour-blind separation, one fixed colour per strategy across all charts, titles and legends outside the data area, direct end-of-line labels.

| Function | Chart |
|---|---|
| `plot_wealth` | growth of 1, log scale, end-of-line labels |
| `plot_drawdowns` | small multiples, annotated MaxDD |
| `plot_rolling(stat="vol" \| "sharpe")` | rolling volatility or Sharpe |
| `plot_metrics` | bars per metric |
| `plot_heatmap` | annotated table (weights, risk contributions, correlations) |
| `plot_weights_through_time` | assets × dates heatmap |
| `plot_correlation` | correlation matrix, custom ordering (e.g. `HRP.order_`) |
| `save_report` | all of the above as PNGs |

Note: Yahoo Finance downloads are tested with a mock, not against the live network; the figures in the docs use simulated data.
